# 库与台账

产物落在一个**独立库**里，和用户自己的知识库隔离。原因：这个 skill 可能被带到别的 agent / 别的机器上用，不能依赖任何私有目录规范和私有插件。

## 一、目录结构

```
course-notes/                     ← 独立库，可单独 git，可整目录拷走
  00-索引.md                      ← 自动生成
  00-课程地图.md                  ← 自动生成
  99-台账.md                      ← 自动生成
  <课程slug>/
    _course.json                  ← 课程配置
    ep31-输入捕获/
      00-知识点.md                ← 共用地基：知识点表 + 时间戳 + 原话 + 截图
      10-讲义.md                  ← 正文（唯一成品）
      90-复查/ep31-review.md      ← 复查表
      assets/
        ep31-t0320-CNT走位.png
        ref/
          ep31-ref-mpu6050-typical.png
          SOURCES.md
  90-题库/quiz.json               ← 与 knowledge_points 的 id 绑定
```

## 二、`_course.json` 配置

```json
{
  "course": "<课程名，会显示在索引/课程地图/台账标题>",
  "slug": "tietoushanyang-hal",
  "source": "<B 站 BV 号>",
  "presentation": "blackboard",
  "discipline": "ee",
  "terms": ["定时器", "预分频器", "捕获", "占空比", "推挽", "开漏"],
  "sections": [{"name": "GPIO", "episodes": [3,4,5,6,7]}],
  "episodes": [{"n": 31, "bvid": "BV1xx", "title": "输入捕获", "duration": 496}],
  "bin": {"ytdlp": "yt-dlp", "ffmpeg": "ffmpeg"}
}
```

- `presentation`：`ppt` / `blackboard` / `mixed` / `handout`——决定抽帧、骨架、谁为准（见 SKILL.md §二·五）；缺省按 `blackboard` 处理但讲义要标"未判定"；
- `discipline`：`math` / `ee` / `physics` / `cs` / `humanities`——决定拓展点、自测题型、红线集；缺省 `ee`（现有红线集最全）；
- `terms` 供转写用（不配则用通用词表）；
- `bin` 不配则从 PATH 找；
- 换课程只换这个文件，不碰代码。

## 三、命名规范

| 对象 | 规则 | 例 |
| --- | --- | --- |
| 集目录 | `ep<两位数>-<主题>` | `ep31-输入捕获` |
| 原片截图 | `ep<NN>-t<时分>-<内容>.png` | `ep31-t0320-CNT走位.png` |
| 网图 | `ep<NN>-ref-<型号>-<用途>.png` | `ep31-ref-mpu6050-typical.png` |
| 复查表 | `90-复查/ep<NN>-review.md` | |
| 知识点 id | `K<序号>_<短名>` | `K2_CCR是什么` |

## 四、自动生成规则（禁止手写状态）

三个文件全部由扫描 frontmatter 生成，任何人手改都会被下次生成覆盖：

1. `00-索引.md`：按课程 → 集 → 知识点 列，带 `status` 与 `evidence`；
2. `00-课程地图.md`：集号 | 标题 | 时长 | 有无讲义 | status | figures；**状态列由文件存在性推出**，不手填；
3. `99-台账.md`：总集数 / 已复查数 / draft 数 / 缺图数 / 复查未通过清单。

为什么要自动：手写台账一定会漂——写了新笔记忘了改地图，读者看到的就是假状态。
（教训来源：某课程地图写着 I2C「❌ 缺」，实际笔记早写好了。）

## 五、与用户私有库的边界

- 默认**不写入**用户的知识库（Obsidian/第二大脑之类）；
- 用户明确要"入库"时才迁移，并保留 `course` / `episode` / `evidence` 字段；
- 迁移后原库目录不再维护，避免两处并存（两处并存＝必然漂移，要清）。

## 六、git

建议独立初始化：

```bash
cd course-notes && git init && printf 'assets/**/*.mp4\nassets/**/*.m4a\n' > .gitignore
```

- 视频/音频不入库（大）；
- 字幕、截图、讲义、复查表入库（这是讲义的可核验依据）；
- 网图若涉版权，只入 `SOURCES.md`，图本身本地保存、不入库。

## 七、最小可用形态

不想建库也能用：单文件输出到 `./<ep31-输入捕获>.md` + 同目录 `assets/`。
此时放弃台账与索引，但**复查表不能省**（可以写在同目录 `review.md`）。

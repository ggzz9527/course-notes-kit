# 图文共讲规范

> 图不是插图，是讲解的主干。零基础看图最大的问题不是图差，是**不知道看哪**。

## 一、一张图必须有的四件东西

1. **引导句**（图前一句）：告诉眼睛落在哪。
   > "现在看这张图，先看左上角那条从 PA0 出来的线。"
2. **标号**：关键元素打 ①②③，正文按号讲。禁止"这个""那个"。
3. **逐点解读**（图后）：①是什么 ②为什么在这 ③动了会怎样。
4. **对照表**：图上标号 | 元件/信号 | 值 | 为什么是这个值。

缺任何一件，这张图算没写完。

## 二、三种图，三种讲法

| 图类型 | 讲法 | 必须回答 |
| --- | --- | --- |
| 原理图 / 接线图 | 指哪讲哪（①②③逐条） | 这三点接错分别会怎样 |
| 时序图 | 时间轴对齐（边沿→时刻→寄存器变化） | 哪个时刻读哪个数 |
| 框图 / 数据流 | 走一遍数据路径 | 数据从哪来、经过谁、到哪去 |

## 三、标号怎么加

- 手工：画图时直接标（自绘图优先）；
- 自动：`scripts/course.py annotate <图> --points "120,80:1 300,200:2"`（Pillow 叠圆点+数字）；
- 标号必须与正文编号一一对应，正文出现 ③ 图上没有③＝不合格。

## 四、一图一义

一张图只承担一个知识点。如果一张图要讲三件事，要么裁成三张，要么删到只剩一件事。
判断标准：这张图能不能用一句话说清"要你看什么"？说不清就拆。

## 五、网上图的核验（强制）

来源优先级：原片截图(S) > 厂商 datasheet / 官方 EVB(A) > 开源硬件/教学站(B) > 自绘(C) > 盗图无来源(禁用)。

**核验三查，三项全过才可用**：

| 查 | 怎么查 | 不过怎么办 |
| --- | --- | --- |
| 型号一致 | 图上丝印/标题与本课芯片型号比对 | 不用 |
| 引脚与外设一致 | 用到的引脚、外设编号与本课一致 | 不用，或标注差异 |
| 关键参数一致 | 电压域、上下拉、去耦、晶振频率 | 不用，或标注差异 |

不一致但确实有用时，正文必须写：`> 注：此图与本课板子差异：<具体差异>。`

**核验记录**（每张网图一条，存 `assets/SOURCES.md`）：

```
ep31-ref-mpu6050-typical.png
  URL: <原始链接>
  fetched: 2026-11-18
  license: <厂商公开手册 / CC-BY / 未标注>
  核验: 型号✓ 引脚✓(PA0/PA1) 参数✓(3.3V, 4.7k 上拉)
  可疑点: 图上是 MPU6050 模块，本课用裸芯片，去耦电容数量不同
```

## 六、版权与分发

- 本地自用：存 URL + 必要截图，标来源，可；
- **skill 本身不打包任何第三方图片**，只给检索词模板 + 复现命令；
- 教材/论文扫描页只存链接，不入库；
- 带水印、无来源、来自博客盗图的，一律不用。

## 七、孤图清理

交付前扫一遍：每张图是否被正文引用（"见图 3"）？没被引用＝删。
图存在但不讲，等于把错误藏进图里。

## 八、按呈现方式选读图策略（2026-11-21 加）

先数要读几张图，再决定用什么读——**不是所有课都值得调视觉模型**。

| 情况 | 怎么读 | 理由 |
| --- | --- | --- |
| **≤10 张**，且是排版好的 PPT/投影 | 会话模型自己 `read_image` 逐张读 | 一次读一张就够准，少一层 API 依赖、省钱省时 |
| **≥30 张**，或需要先筛"哪一帧是完整推导/完整板书" | **用你已配好的视觉模型**批量扫，让它只回"帧号 → 种类 → 遮挡 → bbox"，**不要它的文字** | 人肉逐张看 200+ 帧不现实；批量扫的产出是**筛选**，不是讲义配图 |
| **手写板书**，或公式/表格/符号密集 | **会话模型自己读**（视觉模型只做定位、文字自己抄） | 实测：手写公式的逐字转录，视觉子代理会编；专用 OCR 单帧探测也可能直接 null |
| 需要"边听边理解"（音频+画面二合一） | 你手上**能吃音频**的多模态模型 | 只在本机转写不可用时兜底 |

> **选型只有三条硬指标**：不编造、null 率低、肯标 `[模糊]`。具体型号由你按已配置的模型定；
> 换模型后的验证办法见 SKILL.md ②-B（挑 3 帧已知内容的跑一遍，看它会不会编挡住的部分）。


两条硬规矩：

1. **筛选结果必须回原片核**：视觉模型说"第 37 帧是关键帧"，仍要 `-ss` 重抽一张原图核一遍，不许拿模型的文字描述当图用；
2. **`modlens` 桥在本机没有 vision provider**（2026-11-21 实测报错），别指望它；走 `read_image` 或直接调视觉模型。

`ppt` 型的读图量通常小（一页一结论，挑 6–8 张够）；`blackboard` 型的读图量大（推导跨几十帧），优先走批量扫。

# 其它 agent 的工具映射

这份 skill 的正文按 **DSH 的工具名**写。换 agent 时只需要换「调用名」这一层，
**判据和管线一个字都不用改**——G1–G5 闸门、`note_check` 的 9 类、`--strict` 两档
全在 `tools/` 的 Python 脚本里，谁跑都是同一条命令。

## 一、一一对应表

| 正文里的写法 | 语义 | 通用替代 |
| --- | --- | --- |
| `ops_bash` / `python tools/…` | 执行本地命令 | 平台自带的终端/shell 工具（Claude Code、Cursor 等都有）；**命令行写法不变** |
| `read_image <路径>` | 让**本会话模型**看一张图 | 把图片交给你的多模态模型（平台有专门读图工具就用它） |
| `workflow`（派子代理） | 并行跑 N 个独立的读图/读转写任务 | 平台的子代理/并行任务；**没有就顺序跑**——更慢，结论一样 |
| `write <路径>` | 写文件 | 平台的写文件工具 |
| `skill course-selflearn` | 加载本 skill | 平台的技能机制（技能面板式产品：在面板里启用；Claude Code：`~/.claude/skills/`；其它：把本文当系统提示之一） |
| `present <文件>` | 把产物作为卡片给用户 | 直接给路径或附件 |
| `todo_write` | 任务清单 | 有就用，没有就写在本轮回复里 |

`modlens` 是某台机器上的本地视觉桥，**没有就跳过**，不影响任何闸门。

## 二、换 agent 后先验三件事（顺序固定）

```bash
python scripts/selfcheck.py          # 判据：通过 7 / 警告 1 / 失败 0
python scripts/regress_frames.py     # 判据：通过 6 / 失败 0
python tools/course_gate.py ruler <集目录> --strict   # 没有现成集就跳过
```

**判据**：三条都过，说明「脚本层的判据」在这台机器上成立；之后 agent 换成谁都不影响结论。

## 三、会缺的能力与降级方式

| 缺什么 | 现象 | 降级 |
| --- | --- | --- |
| 多模态读图 | 模型看不到图片 | 用 `look` 裁小图仍读不了 → 该图标「需人工看图」，并在复查表的缺口一栏写明 |
| 子代理并行 | 一次只能跑一个任务 | 顺序跑，每批 ≤ 6 张；只是慢 |
| 本地命令 | 跑不了 Python | **不要接这个活**：管线跑不了，所有闸门失效，只剩"写作文" |
| 长期记忆/库检索 | 没有长期记忆库/知识库那套 | 产物写进独立库 `course-notes/`（`references/库与台账.md` 已定义），不依赖用户的私有库 |

## 四、不随 agent 变的东西

- `tools/` 里的脚本与它们的退出码；
- `references/` 的写作规范与复查清单；
- 集目录约定（`00-知识点.md` / `10-讲义.md` / `90-复查/epNN-review.md`）；
- 媒体目录布局（`<BV>-epN/pN/frames/f_<秒>.png`）。

这四项是**硬边界**：换 agent 后它们仍然成立，所以「换 agent 要重新验一遍流程」的说法不成立，
只需验第二节那三条。

# 一次拉课的完整流程

> 只列机械动作和判据；讲义骨架、红线、复查清单在 `skills/course-selflearn/`。

## 0. 开工前

```bash
python tools/course_run.py fetch <BV> <集>
```

一条命令干完：`meta → 音频 → 转写 → 视频 → 抽帧 → 帧核验`，断点续跑，最后打 `MANIFEST`。

**判据**：MANIFEST 里「失败步骤」必须是「无」；`frames.csv` 行数 = 帧数 + 1（表头）。

## 1. 出知识点卡（不要读全篇转写）

用 `workflow` 派子智能体读 `transcript.srt`，只回卡片。原文不进主会话。

**提示词必须额外要两样产出**：

1. `## 覆盖检查` —— 全片时间轴上哪几段没有卡片（防丢段）；
2. `## 转写疑似错字` —— 「原词→正确词」表（转写常把「硅管」写成「规管」、「毫伏」写成「毫斧」，
   摘要会照抄）。

**判据**：卡片 10–15 条；覆盖检查里「无卡片段」只能是片头/片尾/空档。

## 2. 关键数字回原文核（只读命中行）

```bash
grep -n "0.3\|毫伏\|翻一倍" <媒体目录>/ts.txt
sed -n '455,475p' <媒体目录>/ts.txt      # 只读这几行，绝不 1,1259p
```

**必须核的 6 类**：电压值、时间/温度系数、判据不等式、公式符号、极性、器件名。

**判据**：复查表里每个数字都能指到一条 srt 行号。

## 3. 挑帧 → 落 assets

```bash
python tools/course_run.py shots <集目录> "450:::输入特性" "2280:crop:60,55,720,480:1.6:输出特性曲线"
# 语法：t[:crop:x1,y1,x2,y2[:scale[:名字]]]
```

**判据**：每张图都在正文被引用一次（`note_check` 查「孤图」）。

## 4. 写知识点表 + 讲义

按 `skills/course-selflearn/references/单篇模板.md`。
字数预算 = 知识点数 × 400，合格带上限 = 预算 + 800（带内算合格，别为卡整数反复删句）。

## 5. 自检

三道闸门，**新集一律加 `--strict`**：

| 时机 | 命令 | 查什么 |
| --- | --- | --- |
| 挑帧之前 | `python tools/course_gate.py ruler <集目录> --strict` | 板面矩形量过没有（ep23 漏了，重裁 6 次） |
| 写完讲义 | `python tools/note_check.py <集目录> --frames-csv <媒体目录>/frames.csv` | 9 类机械项：字数带宽 / 单点预算 / 图后解读 / 禁用词 / 坏引用与孤图 / 图号连续性 / 每图有讲解 / frontmatter / status↔复查表 |
| 交付之前 | `python tools/course_gate.py report <集目录> --read-images N --strict` | G1 标尺 + G2 重裁 + G3 读图预算 + G5 拆篇 + 图块与 assets 双向对齐，一次过 |

**判据**：新集三条都退出码 0；`note_check` 的 warn 可以留，FAIL 必须改。

> **两种口径别混**：`ruler` / `parts` 不带 `--strict` 时，缺记录只报 WARN、退出码仍是 0——
> 那是给 30 集历史库巡检用的（25 集没有标尺记录，是 G1 定稿 ep23 之前的欠账，不是新错误）。
> 拿巡检的 rc=0 当「能交付」，正是 ep23 重裁 6 次的成因：**新集交付必须 `--strict`**。

## 6. 复查 → 标 reviewed

按 `references/复查清单.md` 三层查，红线按 `discipline` 取集。
复查表存 `90-复查/epNN-review.md`，frontmatter `status` 改 `reviewed`。

## 7. 台账

```bash
python tools/gen_lib.py <讲义库根目录>
```

## 常见返工点（按频率）

| 返工 | 原因 | 防法 |
| --- | --- | --- |
| 图号跳号 | 插入新图后没重排 | 出稿后立刻跑 `note_check` |
| 孤图 | 生成图但正文没引 | 同上 |
| 单点超 400 | 一个知识点灌太多 | 拆成两个知识点，别删细节 |
| 数字错 | 信了转写卡片没回原文 | 第 2 步强制执行 |
| 时长显示「—」 | `_course.json` 缺 `duration` | 补 `episodes[].duration`，别在脚本里写死 |
| G1 缺标尺记录 | 没先量板面矩形就挑帧 | 挑帧前跑 `ruler <集目录> --strict`（默认档只 WARN，等于没查） |

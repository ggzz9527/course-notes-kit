# 工具与踩坑

> 全部用标准库为主；子进程一律用**重定向到文件**的方式收输出，不用 `capture_output`
> （某些沙箱环境禁命名管道，会 `PermissionError(WinError 5)`）。

## 脚本一览

### `course_run.py` —— 一次拉课的机械段

| 子命令 | 干什么 | 关键参数 |
| --- | --- | --- |
| `fetch <BV> <ep>` | meta→音频→转写→视频→抽帧→帧核验，一条命令 | `--no-video` 只要音频；`--min-frames` 断点阈值；`--force` 全重做 |
| `shots <集目录> <specs...>` | 帧 → 裁切/放大 → `assets/epNN-tNNNN-名字.png` | `t[:crop:x1,y1,x2,y2[:scale[:名字]]]` |
| `check <集目录>` | 转调 `note_check.py` | `--frames-csv`、`--tol` |
| `rank <媒体目录>` | 给出每帧「投影/板书/空板/人物」分类表 | `--every`、`--top` |
| `digest <媒体目录>` | 转调 `course_digest.py` | `--llm` |

**输出一律以 `MANIFEST` 段结尾**（每个文件大小、帧数、时长、转写段数、失败步骤），
一次读完不用再 `ls`。

### `course_prep.py` —— 素材下载

`meta / audio / video / frames / verify` 五个子命令。音频优先：转写只要 20~25 MB，
先下音频就能出稿，不必等整集视频。

### `course_digest.py` —— 转写压缩

```bash
python tools/course_digest.py <媒体目录>          # 机械稿 digest.md（只压到 87%，够查证不够读）
python tools/course_digest.py <媒体目录> --llm    # + 知识点候选卡（走你自己的模型）
```

**已知缺陷（必须知道）**：

1. 摘要**继承转写错字且不加标注**（「恒流」→「横流」、「绝缘栅」→「绝缘山形」）；
2. 分多段调用会**整段丢内容**（实测漏过 8 分钟）。

⇒ 只当「目录 + 时间戳索引」，写讲义必须回 `ts.txt` 核。

### `note_check.py` —— 机械自检（9 类）

字数带宽 / 单点预算 / 图后解读 / 禁用词 / 图片坏引用+孤图 / 图号连续性 /
每张图有无讲解 / frontmatter 必填 / status↔复查表一致。

退出码 0 合格 1 不合格；`--json` 给机器读；`--frames-csv` 追加帧残差核验。

### `course_scan.py` —— 批量筛帧

`list` 出待判清单 + 提示词（`--json` 给 workflow 直接吃），`merge` 并表成段落表。
脚本**自己不调 API**（很多沙箱直连图像 API 会超时），读图交给会话里的 `workflow`。

## 踩坑表

| 坑 | 现象 | 解法 |
| --- | --- | --- |
| `-ss` 放在 `-i` 之后 | 每帧从头解码，292 帧要 40 分钟+ | `-ss` 必须前置 |
| CDN 节点超时 | 整段 TLS 超时 | playurl host 换可达 mirror（签名随路径，换 host 仍有效） |
| ffmpeg 打不开某 CDN | 下载失败 | 用 urllib 分块下载，再本地 ffmpeg 合并 |
| 沙箱禁命名管道 | `subprocess.run(capture_output=True)` → `PermissionError` | 重定向到文件再读回 |
| `av` 版本 | faster-whisper `TypeError: metadata_errors` | 必须 `av==13.1.0`（`av>=15` 删了这个参数） |
| CPU 转写慢 | 默认 beam=5 只有 0.4 倍速 | `WHISPER_BEAM=1`、`WHISPER_THREADS=核数` → 7 倍上下 |
| 后台跑 pip | 假死（输出管道没人读） | 重定向到文件 |
| 帧文件命名 | 猜成 `f0003` 实际是 `f_0030` | 先 `ls` 看命名 |
| 时长列「—」 | `_course.json` 缺 `duration` | 补进 `episodes[].duration` |
| 模型传字符串 | HTTP 400 JSON parse error | 必须传 `messages` 数组 |

## token 账（为什么值得这么折腾）

一集课的固定开销曾经长这样：

| 项 | 数值 |
| --- | --- |
| 175 个工具 schema | ≈ 70,700 token（占首步 95%） |
| 其中桌面操控 63 个 | ≈ 50,493 token，笔记流程一次不用 |
| 首步基线合计 | **74,053** |

**钱不是花在"读笔记"上，是花在"每轮重发用不到的工具说明书"上。**
所以：能外包给子智能体的读原文，一律外包；能落盘的中间产物，一律落盘。

# 选模型：只给判据，不给型号

本仓库**不绑定任何 provider/model**。原因很简单：你手上有什么账号，比任何一个"推荐型号"都重要；
而且型号会过时、会改名、会静默下线。写死一个 id 的结果是——别人 clone 下来跑出一堆
"为什么它没用我选的模型"。

所以这里只给**判据**和**验证办法**。

## 一、三类活儿，三种要求

| 活儿 | 要求 | 省钱做法 |
| --- | --- | --- |
| 读全篇转写出知识点卡 | 能吃长上下文、便宜 | 用你账号里最便宜的文本模型；几十万 token 也不用心疼 |
| 视觉筛帧（几百帧挑 10 张） | **不能编造**、null 率低、肯标 `[模糊]` | 按量计费的低价多模态模型即可，一集只烧几千 token |
| 讲义正文的逐字核对 | 准确率优先 | 直接用你正在用的会话模型，别为这一步换模型 |

**学生讲义这件事有个特殊性**：读者（你）没有纠错能力。所以"编一个像真的公式"
比"返回 null"严重得多——选视觉模型时，**宁可它说不知道**。

## 二、怎么验证一个模型能不能用（三步）

1. **挑 3 帧已知内容的**：一帧完整板书、一帧投影、一帧被人/手挡住的；
2. 让它只回 `kind / occluded / bbox / text`；
3. 看两处：
   - 挡住的那帧，它**会不会把挡住的公式编出来**（会编 → 换模型或降级）；
   - 有没有返回 null（命中率低 → 别用它做批量筛选）。

这三步比任何排行榜都准，因为它测的正是你的课、你的拍摄环境。

## 三、模型 id 怎么写

`provider/model` 带不带前缀，取决于你这台机器怎么注册的。写错的表现很隐蔽：
**不报错，静默回落到默认模型**（子代理照常回结果，但来自另一个模型）。

验证办法：

- 让它回一句"你是哪个模型/谁开发的"，看自报名字；
- 或看调用后的用量归属（账单/日志里挂在哪个 provider 下）。

## 四、不要把 key 传进 git

`tools/llm.json` 已在 `.gitignore` 里。要提交请只提交 `tools/llm.example.json`。

如果曾经把 key 提交过：**先吊销 key**，再清历史（`git filter-repo`），不要只删文件了事。

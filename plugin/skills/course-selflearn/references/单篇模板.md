# 单篇模板

## 一、frontmatter

```yaml
---
course: <课程名，与 _course.json 的 course 一致>
episode: 31
topic: 输入捕获
presentation: blackboard     # ppt | blackboard | mixed | handout
discipline: ee                # math | ee | physics | cs | humanities
knowledge_points: [K1_捕获的本质, K2_CCR是什么, K3_边沿与通道]
evidence: transcript            # transcript | frames+transcript | slides | outline_only
figures: classroom              # classroom | web | redrawn（多种用逗号）
status: draft                   # draft | reviewed
review: 90-复查/ep31-review.md
updated: 2026-11-18
---
```

字段说明：
- `presentation` / `discipline` 两个字段**必填**，判定方法见 SKILL.md §二·五；判不出来写 `mixed` / `ee` 并在正文标"未判定"；
- `evidence` 低等级时，正文顶部必须有降级声明（"仅目录与讲义，未核对原片"）；
- `figures: web` 时，`assets/SOURCES.md` 必须有对应核验记录；
- `status` 只有复查通过才能写 `reviewed`。

## 二、骨架

> 骨架按 `presentation` 分两种。**blackboard 型**用下面这版；**ppt 型**把每个知识点的
> "是什么／为什么需要／机制"换成"结论式／条件／为什么成立"，并把"动手"换成"手推一遍"。

```markdown
# ep31 · 输入捕获

> **30 秒速览**
> - 解决什么问题：……
> - 一句话机制：……
> - 最容易错：……

> 本篇依据：<evidence 说明>。

## 0. 这一集在整门课的位置
前置是什么 → 这集解锁什么 → 后面谁依赖它（一句话各一行）

## 1. 前置补丁
只补"缺了这集就听不懂"的最小一块；够用即停。
不够用的，链到前置篇或单独立篇，不要在这里展开成另一门课。

## 2. 知识点

### K1 · <名字>
**是什么**：一句话。
**为什么需要**：没有它会怎样。
**机制**：<讲解工具箱 ≥2 种手段，≥1 种非文字>
**数字代入**：……
**易错**：错解 → 会看到什么现象。
**自测**：1 题（带答案，答案折叠）。

### K2 · …（同上）

## 3. 动手（最小可跑）
3–6 步，每步写"做什么 + 做完看到什么才算对"。

## 4. 自测
2 题：1 概念 + 1 反例（"如果改成 X 会怎样"）。答案折叠。

## 5. 老师没讲到的
- 留白：老师跳过的前提/结论
- 推测：标 `未核对`，并写为什么这么推
```

## 三、片段示例（可直接模仿）

```markdown
### K2 · CCR 不是"当前计数值"

**是什么**：CCR 是捕获到边沿那一刻，硬件替你抄下来的 CNT 快照。

**为什么需要**：CNT 一直在跑，你看它的时候它已经变了；
要算脉宽，必须有一个"边沿来那一瞬间"的数。

**机制（时间轴 + 反例）**：
上升沿来 → 硬件把 CNT 抄进 CCR1 → CNT 继续跑 → 下降沿来 → 抄进 CCR2。
所以 CCR2 − CCR1＝脉宽。

> 类比：CNT 像秒表一直走，CCR 是按"抄表"那一刻的数字。
> **失效边界**：秒表按暂停就停了，CNT 不停——它只是被抄了一份，读数本身还在涨。

**数字代入**：CNT 走 1 个 tick = 1 µs；CCR2=1500，CCR1=500 → 脉宽 1000 tick = 1 ms。

**易错**：把 CCR 当"当前计数值"去读 → 读数每次都不同，算出来的脉宽乱跳。

**自测**：如果只在上升沿捕获，还能算出脉宽吗？为什么？
```

## 四、排版约定

- 中文标点，段落短（≤4 行）；
- 代码块只放关键几行，标出"看这行"；
- 图用相对路径 `assets/ep31-t0320-xxx.png`，下方一行 `> 图 3 · 来源：原片 03:20 · 要你看：CCR 在哪一刻被更新`；
- 不用花哨装饰、不用 emoji 堆砌。
